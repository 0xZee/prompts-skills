# Prompts & Skills Knowledge Base

A personal knowledge base for storing, organizing, and reusing AI agent prompts and skills across various work domains.

## Structure

- `prompts/<domain>/`: Houses system instructions, personas, and behavioral guidelines scoped to a domain.
- `skills/<domain>/`: Houses reusable tools, automation scripts, and capabilities dedicated to a domain.

## Current Prompts

- `prompts/engineering-code-operating/`: Standard operating procedures for senior software engineering tasks focusing on disciplined execution loops, surgical edits, and verification.
- `prompts/financial-quantitave-analyst/`: Persona guidelines for STOXX, a quantitative equity research analyst specializing in evidence-based asset evaluation and scenario modeling.
